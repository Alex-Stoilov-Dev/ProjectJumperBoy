# Project Jumper Boy
---
#### Project Jumper Boy is a 2D Platformer game, inspired by games like Super Meat Boy, Celeste, and other platformers.

- The game is written with the Godot Engine, using their Scripting Language.
- Assets used in the game are from a free library

The game has the essential platformer features, jumping, gravity, as well as a small testing level for people to experience the game mechanics.
